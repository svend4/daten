# IOS System Production Deployment Guide

## 📋 Overview

This guide covers the complete production deployment of IOS System using Kubernetes.

**Prerequisites:**
- Kubernetes cluster (1.28+)
- kubectl configured
- Docker registry access
- SSL certificates
- Domain names configured

---

## 🚀 Quick Start

### 1. Clone Repository

```bash
git clone https://github.com/your-org/ios-system.git
cd ios-system
```

### 2. Configure Environment

```bash
# Copy environment template
cp .env.production.example .env.production

# Edit configuration
vim .env.production
```

**Required Variables:**
- `DB_PASSWORD` - Strong database password
- `JWT_SECRET_KEY` - 64-character random string
- `ENCRYPTION_KEY` - 32-byte base64 encoded key
- `GRAFANA_ADMIN_PASSWORD` - Grafana admin password
- `AWS_ACCESS_KEY_ID` - AWS credentials for backups
- `AWS_SECRET_ACCESS_KEY` - AWS secret key

**Generate Secrets:**
```bash
# JWT secret (64 chars)
openssl rand -hex 32

# Encryption key (32 bytes, base64)
openssl rand -base64 32
```

### 3. Build Docker Images

```bash
# Build production image
docker build -f Dockerfile.production -t ios-system/api:latest .

# Tag for registry
docker tag ios-system/api:latest ghcr.io/your-org/ios-system/api:latest

# Push to registry
docker push ghcr.io/your-org/ios-system/api:latest
```

### 4. Deploy to Kubernetes

```bash
# Create namespace
kubectl apply -f kubernetes/namespace.yaml

# Create secrets
kubectl create secret generic ios-secrets \
  --from-env-file=.env.production \
  -n ios-system

# Deploy infrastructure
kubectl apply -f kubernetes/postgres-statefulset.yaml
kubectl apply -f kubernetes/redis-deployment.yaml
kubectl apply -f kubernetes/elasticsearch-deployment.yaml
kubectl apply -f kubernetes/qdrant-deployment.yaml

# Wait for databases to be ready
kubectl wait --for=condition=ready pod \
  -l app=postgres \
  -n ios-system \
  --timeout=300s

# Deploy application
kubectl apply -f kubernetes/api-deployment.yaml
kubectl apply -f kubernetes/celery-deployment.yaml

# Deploy monitoring
kubectl apply -f kubernetes/prometheus-deployment.yaml
kubectl apply -f kubernetes/grafana-deployment.yaml

# Deploy ingress
kubectl apply -f kubernetes/ingress.yaml

# Enable autoscaling
kubectl apply -f kubernetes/hpa.yaml
```

### 5. Verify Deployment

```bash
# Check all pods
kubectl get pods -n ios-system

# Check services
kubectl get svc -n ios-system

# Check ingress
kubectl get ingress -n ios-system

# View logs
kubectl logs -f deployment/ios-api -n ios-system
```

### 6. Access Application

```bash
# Get ingress IP
kubectl get ingress ios-ingress -n ios-system

# Test health endpoint
curl https://api.ios-system.com/health
```

## 🚨 Incident Response

### High Error Rate

**Symptoms:**
- Error rate > 5%
- Alert: `APIHighErrorRate`

**Investigation:**

```bash
# Check error logs
kubectl logs -f deployment/ios-api -n ios-system | grep ERROR

# Check error metrics
curl http://prometheus:9090/api/v1/query?query='rate(http_requests_total{status=~"5.."}[5m])'

# Check recent deployments
kubectl rollout history deployment/ios-api -n ios-system
```

**Resolution:**

```bash
# If caused by recent deployment, rollback
kubectl rollout undo deployment/ios-api -n ios-system

# Scale up if capacity issue
kubectl scale deployment/ios-api --replicas=10 -n ios-system

# Restart if memory leak
kubectl rollout restart deployment/ios-api -n ios-system
```

### Database Connection Pool Exhausted

**Symptoms:**
- `ConnectionPoolExhausted` errors
- Alert: `PostgresHighConnections`

**Investigation:**

```bash
# Check active connections
kubectl exec -it statefulset/postgres -n ios-system -- \
  psql -U ios -d ios_production -c "SELECT count(*) FROM pg_stat_activity;"

# Check connection sources
kubectl exec -it statefulset/postgres -n ios-system -- \
  psql -U ios -d ios_production -c "SELECT client_addr, count(*) FROM pg_stat_activity GROUP BY client_addr;"
```

**Resolution:**

```bash
# Increase max connections (temporary)
kubectl exec -it statefulset/postgres -n ios-system -- \
  psql -U ios -d ios_production -c "ALTER SYSTEM SET max_connections = 300;"
kubectl rollout restart statefulset/postgres -n ios-system

# Adjust application pool size
kubectl set env deployment/ios-api DB_POOL_SIZE=30 -n ios-system

# Terminate idle connections
kubectl exec -it statefulset/postgres -n ios-system -- \
  psql -U ios -d ios_production -c "SELECT pg_terminate_backend(pid) FROM pg_stat_activity WHERE state = 'idle' AND state_change < NOW() - INTERVAL '10 minutes';"
```

### Out of Memory (OOM)

**Symptoms:**
- Pods restarting
- `OOMKilled` status
- Alert: `ContainerMemoryHigh`

**Investigation:**

```bash
# Check memory usage
kubectl top pods -n ios-system

# Check pod events
kubectl describe pod <pod-name> -n ios-system | grep -A 10 Events

# Analyze memory consumption
kubectl exec -it <pod-name> -n ios-system -- ps aux --sort=-%mem | head -20
```

**Resolution:**

```bash
# Increase memory limit
kubectl set resources deployment/ios-api \
  --limits=memory=8Gi \
  --requests=memory=4Gi \
  -n ios-system

# Check for memory leaks in code
kubectl logs <pod-name> -n ios-system > logs.txt
# Review logs for memory growth patterns

# Restart affected pods
kubectl delete pod <pod-name> -n ios-system
```

### Disk Space Full

**Symptoms:**
- Cannot write to disk
- Database errors
- Alert: `PostgresDiskSpace`

**Investigation:**

```bash
# Check disk usage
kubectl exec -it statefulset/postgres -n ios-system -- df -h

# Find large files
kubectl exec -it statefulset/postgres -n ios-system -- du -sh /var/lib/postgresql/data/*

# Check log sizes
kubectl exec -it deployment/ios-api -n ios-system -- du -sh /app/logs
```

**Resolution:**

```bash
# Clean old logs
kubectl exec -it deployment/ios-api -n ios-system -- \
  find /app/logs -name "*.log" -mtime +7 -delete

# Vacuum database
kubectl exec -it statefulset/postgres -n ios-system -- \
  psql -U ios -d ios_production -c "VACUUM FULL;"

# Expand PVC (if supported)
kubectl patch pvc postgres-storage-postgres-0 \
  -p '{"spec":{"resources":{"requests":{"storage":"100Gi"}}}}' \
  -n ios-system
```

## 🔧 Maintenance Tasks

### Database Maintenance

**Routine Maintenance (Weekly):**

```bash
# Connect to database
kubectl exec -it statefulset/postgres -n ios-system -- \
  psql -U ios -d ios_production

-- Run vacuum
VACUUM ANALYZE;

-- Update statistics
ANALYZE;

-- Check index bloat
SELECT schemaname, tablename, indexname,
  pg_size_pretty(pg_relation_size(indexrelid)) AS index_size
FROM pg_stat_user_indexes
ORDER BY pg_relation_size(indexrelid) DESC
LIMIT 20;

-- Reindex if needed
REINDEX DATABASE ios_production;
```
